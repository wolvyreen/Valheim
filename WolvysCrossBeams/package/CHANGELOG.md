# Changelog

## 1.0.2 (2026-11-06)
Tidied up how the snap points are compared (they're now read exactly where the game has them), and the check does less work while you're building.

## 1.0.1 (2026-11-06)
Duplicates are now spotted by their snap points instead of by angle. 1.0.0 had a gap where a copy that had just been turned round (a beam turned 180°, a pole, a square floor turned 90°) could slip inside an existing piece. That's blocked again.

## 1.0.0 (2026-11-06)
First release.
